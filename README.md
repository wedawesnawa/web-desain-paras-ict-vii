# Eracycle

> A responsive landing page designed during the **Paras ICT VII 2022 Web Design Competition**. The challenge was to create a static website within **3 hours of live coding** based on the theme **waste recycling** using the provided design resources and libraries.

---

## 📖 About

EraCycle is a static landing page developed as part of the **Paras ICT VII 2022 Web Design Competition** for Senior/Vocational High School students. Participants were challenged to design and build a responsive website in only **3 hours** through an offline live coding session.

The website introduces a conceptual waste recycling platform that highlights its mission, services, benefits, and call-to-action through a clean and modern user interface.

## 🎯 Challenge

The biggest challenge of this project was designing and implementing a visually appealing landing page within a strict **3-hour live coding session**. Besides writing clean HTML and CSS, the interface had to effectively communicate the concept of a waste recycling platform while maintaining responsiveness and a consistent visual hierarchy.
